OpenSCENARIO Editor

Testszenarien für CARLA zusammenklicken — in sechs Schritten.

  1. Karte wählen — Stadt auf der leeren Karte anklicken oder eine .xodr hineinziehen.
  2. Ego platzieren — Ego links wählen, auf eine Spur klicken. Fahrzeugtyp rechts unter Typ.
  3. Verkehr hinzufügen — Fahrzeuge, Personen, Requisiten setzen. Oder rechts unter Templates / oben Generieren ein fertiges Szenario.
  4. Events geben — Akteur wählen, rechts WENN Auslöser → DANN Aktion (Route, Tempo, Spurwechsel …).
  5. Umgebung — oben Umgebung: Wetter-Voreinstellung, Tageszeit und Hintergrundverkehr.
  6. Prüfen & exportieren — Leertaste spielt die Vorschau, dann Export .xosc. Datei speichert als .json.
