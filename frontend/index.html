OpenSCENARIO Editor

Visueller Szenario-Editor für autonomes Fahren (CARLA)

Erstellen Sie komplexe Testszenarien für autonome Fahrzeuge im OpenSCENARIO 1.0-Format — ohne eine einzige Zeile Code zu schreiben. Platzieren Sie Akteure, zeichnen Sie Trajektorien und exportieren Sie direkt für den CARLA ScenarioRunner.

1
Karte auswählen Wählen Sie im Dropdown oben eine der 9 CARLA-Stadtkarten (Town01–Town10HD).
2
Ego-Fahrzeug platzieren Klicken Sie auf Ego in der linken Werkzeugleiste, dann auf die Karte. Das Fahrzeug rastet automatisch am nächsten Startpunkt ein.
3
Route des Ego zeichnen Wählen Sie das Ego auf der Karte → klicken Sie rechts auf Zeichnen → setzen Sie Wegpunkte durch Klicken → Fertig.
4
NPC-Akteure hinzufügen Werkzeuge: Auto, LKW, Bus, Motorrad, Fußgänger, Radfahrer. Gleiche Vorgehensweise wie beim Ego. NPCs erhalten Events wie das Ego.
5
Umgebung konfigurieren Nutzen Sie die Wetterleiste unten: Tageszeit, Nebel, Regen, Wolken, Sonne, nasse Straße, Schnee, Staub (je 0–1).
6
Vorschau & Export Mit ▶ Abspielen animieren Sie das Szenario. Exportieren Sie als .xosc (OpenSCENARIO), als Route-.xml (Autoware) oder speichern Sie als .json zum Weitarbeiten.
